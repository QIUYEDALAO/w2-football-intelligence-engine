# F5 · 盘口变动强度/不稳定度预注册（设计冻结）

状态：`PREMISE_TEST_ONLY`。这是**单机构时序不稳定度**，不称机构分歧；不接入推荐档位。

- 目标：先检验高变动强度是否预示更大的结果偏差或更差的每注盈亏，只有前提成立才设计只降不升规则。
- 样本：F4 同一前向 PIT 报价序列、同一评估快照和 fixture 级密封拆分；缺双侧、缺初盘或时间倒挂均按预先冻结原因排除，并列出覆盖率。
- 指标：以赛前相同时间窗的绝对盘口线变化、去水概率变化及方向反转次数构成强度；阈值仅由训练集分位数冻结为低/中/高桶。逐桶报告 n、唯一 fixture、缺失率、bias、五态 logloss 与纯/含返水均注盈亏，按联赛和 AH/TOTALS 分层。
- 前提门：高强度相对低强度的绝对 bias 与亏损风险须在独立 OOS fixture 聚类 bootstrap CI 显示稳定增大；同时检查强度对结果/盈亏的增量，避免仅重复当前市场锚。任一市场无足够样本或方向不稳，结论为证据不足/否决，不开工。
- 若前提通过：另行冻结只能降档、不能升档的映射及回退开关并预注册前向验收。当前无档位、EV、推荐或自动调参修改。
