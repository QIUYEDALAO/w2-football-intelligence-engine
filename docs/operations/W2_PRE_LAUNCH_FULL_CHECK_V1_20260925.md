# W2 上线前全面检测方案（v1.0 · 2026-09-25）

检测范围：本批上线内容 = R0 返水统一、Track B/C/D 离线实现、R1 追加式证据层、前向时钟（T0）、监测块（6 类信号）、F4/F5/F6 单独立项、R5 周报。
