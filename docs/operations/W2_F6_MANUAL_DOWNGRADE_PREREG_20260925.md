# F6 · 人工降档因子预注册（规则先冻结）

状态：`RULE_FREEZE_ONLY`。没有写入通道、权限实现或推荐链路接线。

- 目标：人工确认伤停、轮换或战意信息后，只能降档或拦截，绝不升档、改选边或覆盖模型概率。
- 触发时点：必须在该场 T-30 锁定时点之前记录并由服务器校验 `recorded_at<lock_at`；晚到标记 `TOO_LATE`，仅供复盘。不能用赛后信息追写赛前标注。
- 权限：仅 Owner 指定的操作员可以创建；不同人复核后生效。身份、时间、来源、原文摘要、fixture、market、原档位、目标档位、必填原因码一并追加记录。
- 原因码：`INJURY_CONFIRMED`、`LINEUP_ROTATION_CONFIRMED`、`MOTIVATION_VERIFIED`、`SOURCE_CONFLICT`；自由文本仅作说明，不得替代原因码。无法证明来源时间/身份时 fail-closed，不生效。
- 有效期：单场单 market，最迟到 kickoff；若赛程更改，旧标注失效并需重审，不自动移植。
- 回退：仅可追加 `REVOKED` 事件，保留原标注及原因；撤销后恢复原模型档位，不补发已过锁定时点的推荐。独立开关关闭后全部标注仅供只读审计。
- 验收设计：先构造锁前/锁后、无权操作者、缺原因、过期、撤销和并发冲突用例；前向分组报告已标注/未标注的覆盖率和结果，不把观察性比较解释为因果收益。接线需另一次 Owner 授权与独立预注册。
