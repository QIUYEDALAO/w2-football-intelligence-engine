# F4 · 盘口移动特征预注册（设计冻结）

状态：`DESIGN_ONLY`。不接入推荐、融合或生产因子门。冻结基线为当前 xG + 已冻结 Track B/C/D 融合；任何改动另开预注册。

- 目标：检验 Pinnacle 初盘至评估时点的线差、水差、方向和最近移动时间，能否在**同一批 fixture、同一评估时点**提供基线之外的增量。
- 样本：仅使用 T_start 后、赛前已捕获且可证明 PIT 的同机构、同盘口、同双侧报价序列；每 fixture×market 只用预先固定的评估时点。缺初盘或末盘者单列缺失，不用未来报价填补。按 fixture 分组划分训练、validation、test，锁定测试集后不得调特征。
- 验收：与 xG + 融合基线逐笔配对，分别报告 AH/TOTALS 的五态 logloss、Brier、RPS、bias、市场基准和均注盈亏；主指标为 OOS logloss 改善的 fixture 聚类 bootstrap 95% CI 全部小于 0，并报告覆盖率及各联赛方向。没有样本量与 CI 不宣布通过。
- 消融：基线、基线+移动、去掉当前市场锚仅用移动三组同批比较；若移动特征只是当前去水概率或 λ 锚的确定性变换，判定同源重复计价并停止。训练输入特征清单与市场报价 observation_id 一并冻结，严禁同一信息源在 λ 市场融合与特征层重复计价。
- 泄漏保护：移动截止 `captured_at≤evaluated_at<kickoff_utc`，赛果与赛后盘口不可作为输入。失败仅保留只读归因维度；接入融合需新的 Owner 决议。
