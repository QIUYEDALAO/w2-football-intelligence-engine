## 度量

生产准入为 `cashflow_price_edge = d/F − 1 >= 0.05`，即报价达到 `1.05 × F` 时准入。
两个模型给出不同准入决策的报价区间,恰为 `1.05×F_A` 与 `1.05×F_B` 之间。
因此**决策相关分歧**可以完全不依赖任何报价来度量：

```text
r = | F_challenger / F_comparator − 1 |
```

`r >= 0.05` 意味着两模型的分歧达到整个准入 margin 的宽度，
即存在现实报价使一个模型准入而另一个不准入。

## 主结果

`78,256` 个 fixture-line 观测。

```text
r 分位数   P10 0.0144   P25 0.0324   P50 0.0654   P75 0.1171
           P90 0.1790   P95 0.2228   P99 0.3252

r >= 0.025   81.4%
r >= 0.050   60.5%
r >= 0.100   32.0%
```

**中位分歧 `6.5%`，已超过准入 margin 本身。六成观测的分歧达到或超过整个 margin 宽度。**

**分歧集中在中低概率区，在极端高概率区几乎消失。**
`|ΔNLL|` 的峰值出现在 `[0.4,0.5)`，同区 `r >= 0.05` 的比例为 `78.0%`。

按专家提出的判据，这属于：

```text
disagreement concentrates near the decision boundary
=> 给定的 ΔNLL 携带高决策权重
```

而不是集中在 `90% -> 91%` 那类对决策无影响的极端区。

## ΔNLL 与决策相关性并非独立

```text
r >= 0.05 的观测占 60.5%，却贡献了 82.7% 的总 |ΔNLL|
corr(r, |ΔNLL|) = 0.5322
```

**NLL 改善主要就发生在决策相关的地方**，两者不是彼此独立的量。

## 对 `δ_promote` 的意涵（仅为论证输入，不设定阈值）

按预注册的解释规则，本结果支持「分歧集中于决策边界附近」这一分支，
因此**给定的 `ΔNLL` 在本系统中携带较高决策权重**，
`δ_promote` 有理由不必设得很高。

但本分析**不设定** `δ_promote`。它只排除了一种可能性：
即「模型差异全落在对下注决策无影响的极端概率区、因此需要很大的 ΔNLL 才值得换模型」。
该可能性在本 cohort 上不成立。
