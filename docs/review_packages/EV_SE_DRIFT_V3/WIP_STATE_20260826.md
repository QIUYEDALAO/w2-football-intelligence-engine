   Codex 第 6 条批评成立。但在真正要紧的 σ²≈1e-4（60 天抬高 SE 10%）上，
   即便有效估计量也只有 **17.2%** 功效，远低于 80%。
   → 「不可识别」的定性结论仍然成立，但现在是用**有效估计量**确立的，强得多。
